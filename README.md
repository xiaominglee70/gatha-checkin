# 偈语背诵打卡小程序 · Supabase 版

## 部署到 Render 的步骤

### 1. 环境变量（Render 中配置）
- `SUPABASE_URL` = 你的 Supabase Project URL
- `SUPABASE_SERVICE_KEY` = 你的 Supabase Secret key (service_role)
- `BOT_TOKEN` = 你的 Telegram Bot Token（可选）

### 2. Render 设置
- Build Command: `npm install`
- Start Command: `node server.js`
- Instance Type: Free

### 3. 默认管理员
- 用户名: admin
- 密码: admin123
- 首次登录后请立即修改密码
